# SecureChat

**Built By Johnathan Carlson**

A secure team messaging application with military-grade encryption.

## Features

- End-to-end encrypted messaging
- Team collaboration with roles
- Ghost mode sessions
- Call sign system
- Self-destructing messages
- Voice messages
- Message reactions
- Typing indicators
- PIN lock protection
- Panic mode (emergency data wipe)
- Location sharing

## Tech Stack

- React 18 + TypeScript
- Firebase (Auth, Firestore, Storage)
- Tailwind CSS + shadcn/ui
- Vite
- Capacitor (mobile support)

## Getting Started

```sh
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
